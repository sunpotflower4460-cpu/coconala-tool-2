# はじめにお読みください

このたびは「見積・請求書デスク」をご購入いただき、ありがとうございます。

## このzipに入っているもの

| ファイル                                                  | 内容                       |
| --------------------------------------------------------- | -------------------------- |
| インストーラー(Mac: `.dmg` / Windows: `-setup.exe`)       | アプリ本体                 |
| `はじめにお読みください.pdf`                              | この案内とインストール手順 |
| `クイックスタートガイド.pdf`                              | 初回設定(5〜10分)の手順    |
| `ユーザーマニュアル.pdf`                                  | 各画面の使い方・困ったとき |
| `利用規約.pdf` / `免責事項.pdf`                           | ご利用の条件               |
| `samples/顧客サンプル.csv` / `samples/価格表サンプル.csv` | CSV取り込みの見本          |

## 最初にすること

1. 下の「インストール手順」に沿ってアプリを入れます。
2. アプリを起動し、画面の案内(初回設定)に沿って会社情報・顧客・価格表を登録します。
3. 左のメニューの「バージョン情報」で、トークルームでお届けした **ライセンスキー**(「MDK1.」で始まる文字列)を登録します。
4. 見積を1件作って発行し、印刷画面から PDF を保存してみます。
5. 「データ管理」でバックアップを作成します(定期的なバックアップをおすすめします)。

## 大切なこと

- データはお使いのパソコンの中だけに保存されます。販売者を含め、外部へは送られません。
- AI 文章読み取りは任意の機能です。使わなくても、見積・請求・納品・領収書はすべて作れます。
- 金額や税の記載内容は、発行前にご自身で確認してください。

## 更新とお問い合わせ

- 新しい版は、ココナラのメッセージでお届けします(自動更新はありません)。
- お問い合わせは、ご購入時のトークルーム(取引完了後はココナラのダイレクトメッセージ)でお願いします。
  不具合のときは、「データ管理」の「診断ファイルを保存」で作ったファイルを添えてください(顧客名などの個人情報は含まれません)。
