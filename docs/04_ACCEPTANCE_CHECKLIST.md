# 04 — 販売可能判定チェックリスト

## A. インストール

- [ ] macOSの対応バージョンへインストールできる
- [ ] Windowsの対応バージョンへインストールできる
- [ ] 初回起動で警告・失敗がない
- [ ] アプリのバージョンを確認できる
- [ ] アンインストール時のデータ扱いが説明される

## B. 初回設定

- [ ] 会社名、住所、連絡先、振込先、ロゴを登録できる
- [ ] 後で続けられる
- [ ] 入力例がある
- [ ] 必須項目が分かる
- [ ] テスト書類まで案内される

## C. 価格表

- [ ] 手動登録できる
- [ ] CSV見本を取得できる
- [ ] CSV列を選択できる
- [ ] 取り込み前に内容を確認できる
- [ ] エラー行が分かる
- [ ] 重複時の動作を選べる
- [ ] 5000件で検索できる

## D. 見積

- [ ] AIなしで作れる
- [ ] 顧客を選べる
- [ ] 明細を検索・追加できる
- [ ] 数量、単価、税率、値引きを変更できる
- [ ] 合計計算が仕様どおり
- [ ] 下書き保存できる
- [ ] 再起動後に再表示できる

## E. AI

- [ ] AIを使わない選択肢がある
- [ ] APIキーを安全に保存・削除できる
- [ ] 送信内容が分かる
- [ ] AI結果をスキーマ検証している
- [ ] 緑・黄・赤と文字ラベルがある
- [ ] 不明項目を勝手に確定しない
- [ ] AI失敗後に手動へ切り替えられる
- [ ] 金額は価格表からのみ候補化される

## F. 帳票

- [ ] 見積書
- [ ] 請求書
- [ ] 納品書
- [ ] 領収書
- [ ] 発行済み書類が後から変わらない
- [ ] A4印刷できる
- [ ] PDF保存できる
- [ ] 2ページ以上が崩れない
- [ ] 長い日本語が欠けない
- [ ] ロゴあり・なしで崩れない

## G. データ安全性

- [ ] 外部キーが有効
- [ ] migration失敗時の保護がある
- [ ] バックアップを作れる
- [ ] バックアップの破損を検知できる
- [ ] 復元前に現データを退避する
- [ ] 復元失敗時に元へ戻る
- [ ] 発行履歴が残る

## H. セキュリティ

- [ ] APIキーがDB平文にない
- [ ] APIキーがログにない
- [ ] APIキーが診断にない
- [ ] 顧客情報が診断にない
- [ ] Tauri権限が最小限
- [ ] 任意Shell実行を許可していない
- [ ] 更新ファイルを署名検証する
- [ ] 秘密鍵をリポジトリに置いていない

## I. 自己解決

- [ ] 練習モードがある
- [ ] 練習データを削除できる
- [ ] 画面内ヘルプがある
- [ ] FAQがある
- [ ] 5分操作動画がある
- [ ] 診断ファイルを作れる
- [ ] サポート範囲が明確

## J. 初心者テスト

- [ ] 初心者5人が試した
- [ ] 4人以上が初回設定を完了
- [ ] 4人以上が見積を作成
- [ ] 4人以上がPDF保存
- [ ] 4人以上がバックアップ作成
- [ ] 迷った専門用語を修正済み

## K. リリース

- [ ] CIが通る
- [ ] Unit testが通る
- [ ] Integration testが通る
- [ ] E2Eが通る
- [ ] Rust clippyが警告ゼロ
- [ ] macOS署名・公証済み
- [ ] Windows署名済み
- [ ] 更新テスト済み
- [ ] CHANGELOGあり
- [ ] 利用規約・免責あり
- [ ] インストールガイドあり

## 販売停止条件

次のいずれかが確認された場合、解消するまで販売・更新公開を停止する。

- 金額計算の重大な誤り
- データ消失
- 復元不能
- APIキー・顧客情報の漏えい
- 発行済み書類が後から変化
- 更新による起動不能
- 主要OSでの継続的なクラッシュ
