# ベータテスト観察シート

`docs/02_DEVELOPMENT_PHASES.md` Phase6のベータテスト(5〜10人)で使う観察記録テンプレート。1人につき1シートを作成する。観察者は極力手助けせず、迷った箇所・誤操作・理解できなかった言葉をそのまま記録する。

## 基本情報

- 実施日:
- 対象者ID(氏名は記録しない。個人情報保護のためA・B・C等の記号を使う):
- OS(macOS / Windows)・バージョン:
- 観察者:

## 依頼した操作(Phase4ユーザビリティ試験と共通)

1. 初回設定
2. 商品3件登録
3. 顧客登録
4. 問い合わせから見積作成
5. PDF保存
6. バックアップ作成

## 観測項目

| 項目                                  | 記録 |
| ------------------------------------- | ---- |
| 初回設定の完了(はい/いいえ)           |      |
| 初回設定に要した時間                  |      |
| 最初の見積作成までの時間              |      |
| CSV取り込みを試したか(はい/いいえ)    |      |
| CSV取り込みの失敗有無・内容           |      |
| AI候補をどれだけ修正したか(件数/割合) |      |
| PDF保存に成功したか(はい/いいえ)      |      |
| 迷った操作・画面                      |      |
| 誤操作の内容                          |      |
| 理解できなかった言葉・表現            |      |
| 「期待していたができなかったこと」    |      |
| サポートへの問い合わせ内容(あれば)    |      |

## リリース判断に関わる重大事象チェック(1件でも該当すれば正式販売しない)

- [ ] 重大な計算誤りが発生した
- [ ] データが消失した
- [ ] バックアップから復元できなかった
- [ ] 秘密情報(APIキー等)が漏えいした、または診断ファイルに含まれた
- [ ] 発行済み書類の内容が事後に変化した
