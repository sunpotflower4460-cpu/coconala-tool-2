# 5分操作動画 台本

購入者向けに操作を紹介する動画の台本。実際の収録時は、練習モードで作成したサンプルデータを使う(実データを映さない)。

## 想定時間配分

| 区間 | 時間      | 内容                                               |
| ---- | --------- | -------------------------------------------------- |
| 1    | 0:00-0:30 | オープニング・このアプリでできること               |
| 2    | 0:30-1:30 | 初回設定(会社情報・税設定・顧客・価格表・練習見積) |
| 3    | 1:30-2:30 | 見積書の作成・印刷(PDF保存)                        |
| 4    | 2:30-3:30 | 見積書→請求書への変換、状態の遷移                  |
| 5    | 3:30-4:15 | AI文章読み取り機能の紹介(任意機能であることを明言) |
| 6    | 4:15-5:00 | バックアップ・データ管理・ヘルプの案内、締め       |

## 台本

### 1. オープニング(0:00-0:30)

> 「見積・請求書デスク」は、インターネットに接続しなくても使える見積書・請求書作成アプリです。
> 作ったデータはすべてこのパソコンの中に保存され、外部に送信されることはありません。
> 今日は、はじめて使う方向けに、基本の操作を5分でご紹介します。

### 2. 初回設定(0:30-1:30)

- アプリを起動すると表示される「初回設定をはじめる」ボタンを押す。
- 会社情報(会社名・振込先など)を入力して次へ。
- 消費税の端数処理(切り捨て推奨)を選んで次へ。
- サンプルの顧客を1件登録。
- サンプルの商品・サービスを1件登録。
- 「練習用の見積を作る」を押し、実際に見積が1件できることを見せる。

> 「ここまでの入力は、あとからいつでも変更できます。まずは1件ずつ登録してみましょう。」

### 3. 見積書の作成・印刷(1:30-2:30)

- 「見積書」→「新しい見積書を作る」から、顧客・明細を選んで見積を作成。
- 「発行」ボタンを押し、書類番号が採番されることを見せる。
- 印刷画面から、OS標準の印刷ダイアログで「PDFとして保存」を選ぶ手順を見せる。

> 「発行した書類は、あとから金額が変わらないように内容が固定されます。修正したい場合は複製してから編集してください。」

### 4. 見積書→請求書への変換(2:30-3:30)

- 発行済みの見積書から「請求書に変換」を実行。
- 請求書側で内容を確認し、発行する。
- 状態(承認・入金など)の変更ボタンを見せる。

### 5. AI文章読み取り機能(3:30-4:15)

- 「AI設定」画面を開き、この機能が任意であること、契約している外部AIサービスのAPIキーが必要なことを説明する。
- 「問い合わせ読み取り」画面で、サンプルの問い合わせ文から明細候補が抽出される様子を見せる(実際のAPIキーがない場合は、画面の説明のみで代替する)。

> 「AIはあくまで下書きの手伝いをするだけで、金額の決定や書類の送信は行いません。使わなくても、すべての機能は問題なく使えます。」

### 6. データ管理・締め(4:15-5:00)

- 「データ管理」画面で、バックアップ作成・練習データの一括削除・診断ファイルの保存を紹介する。
- 「ヘルプ」画面にFAQがあることを案内する。

> 「操作でわからないことがあれば、ヘルプ画面のFAQをご確認ください。それでも解決しない場合は、データ管理画面から診断ファイルを保存してお問い合わせください。診断ファイルに個人情報は含まれません。以上で基本操作の紹介を終わります。」
