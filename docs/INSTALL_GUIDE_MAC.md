# インストール手順(Mac)

「見積・請求書デスク」を Mac に入れる手順です。所要時間は5分ほどです。

## 必要なもの

- macOS 11(Big Sur)以降の Mac(Apple シリコン・Intel のどちらでも使えます)
- ココナラのトークルームでお届けした `MitsumoriDesk_<バージョン>_mac.zip`
- ライセンスキー(トークルームのメッセージに記載。「MDK1.」で始まる文字列)

## 手順

1. トークルームから `MitsumoriDesk_<バージョン>_mac.zip` をダウンロードします。
2. ダウンロードした zip をダブルクリックして開きます。中に `.dmg` ファイルと説明書(PDF)が入っています。
3. `.dmg` ファイルをダブルクリックします。
4. 開いたウィンドウで、「MitsumoriDesk」のアイコンを「Applications(アプリケーション)」フォルダへドラッグします。
5. 「アプリケーション」フォルダの「見積・請求書デスク」をダブルクリックして起動します。
6. 「インターネットからダウンロードされたアプリケーションです。開いてもよろしいですか?」と表示されたら「開く」を押します。

### 「開発元を検証できないため開けません」と表示された場合

販売者から「署名なし(β版)」と案内された版を使っているときだけ表示されます。

1. 表示されたメッセージは「完了」(または「OK」)で閉じます。
2. 「システム設定」→「プライバシーとセキュリティ」を開きます。
3. 下の方にある「"見積・請求書デスク"は開発元を確認できないため…」の横の「このまま開く」を押します。
4. パスワード(または Touch ID)で確認すると起動します。次回からは普通に起動できます。

## 起動したら

1. 画面の案内に沿って初回設定をします(`クイックスタートガイド` を参照)。
2. 左のメニューの「バージョン情報」で、ライセンスキーを貼り付けて「登録する」を押します。
   登録しなくても使えますが、印刷・PDFに「未認証版」と入ります。

## 新しい版への更新

1. 新しい版は、ココナラのメッセージでお届けします(自動更新はありません)。
2. 更新の前に「データ管理」→「バックアップを作成」を押します。
3. 新しい `.dmg` を開き、同じように「Applications」へドラッグして「置き換える」を選びます。
4. 起動して、書類や顧客がそのまま残っていることを確認します。

## データの保存場所

データはこの Mac の中だけに保存されます(販売者のサーバーには送られません)。

- 保存場所: `~/ライブラリ/Application Support/com.mitsumoridesk.desktop/`
- アプリを「ゴミ箱」に入れても、この場所のデータは消えません。
- 別の Mac へ移るときは、「データ管理」でバックアップを作成し、一覧の「外部フォルダへ書き出す」で USB メモリなどへ保存します。新しい Mac では「データ管理」→「外部フォルダから取り込む」で読み込み、一覧から復元します。
