# インストール手順(Windows)

「見積・請求書デスク」を Windows に入れる手順です。所要時間は5分ほどです。

## 必要なもの

- Windows 10 / 11(64ビット)
- ココナラのトークルームでお届けした `MitsumoriDesk_<バージョン>_windows.zip`
- ライセンスキー(トークルームのメッセージに記載。「MDK1.」で始まる文字列)
- 管理者権限は不要です(自分のユーザーにだけインストールします)

## 手順

1. トークルームから `MitsumoriDesk_<バージョン>_windows.zip` をダウンロードします。
2. zip を右クリックして「すべて展開」を選びます。中にインストーラー(`MitsumoriDesk_<バージョン>_x64-setup.exe`)と説明書(PDF)が入っています。
3. インストーラーをダブルクリックします。

### 「WindowsによってPCが保護されました」と表示された場合

このアプリは個人の販売者が配布しているため、Windows の SmartScreen という仕組みにより、初回にこの画面が出ることがあります。

1. 画面の「詳細情報」を押します。
2. 表示された「実行」ボタンを押します。

(ウイルス対策ソフトが確認画面を出した場合も、配布元がココナラのトークルームであることを確かめてから許可してください。)

4. インストーラーの案内(日本語)に沿って「次へ」→「インストール」を押します。
5. 完了すると、スタートメニューの「見積・請求書デスク」から起動できます。

## 起動したら

1. 画面の案内に沿って初回設定をします(`クイックスタートガイド` を参照)。
2. 左のメニューの「バージョン情報」で、ライセンスキーを貼り付けて「登録する」を押します。
   登録しなくても使えますが、印刷・PDFに「未認証版」と入ります。

## 新しい版への更新

1. 新しい版は、ココナラのメッセージでお届けします(自動更新はありません)。
2. 更新の前に「データ管理」→「バックアップを作成」を押します。
3. 新しいインストーラーをそのまま実行して上書きインストールします(先にアンインストールする必要はありません)。
4. 起動して、書類や顧客がそのまま残っていることを確認します。

## アンインストールするときの注意

アンインストールの画面に「アプリのデータを削除する」という意味のチェックが出ることがあります。
**これにチェックを入れると、作成した書類・顧客・価格表がすべて消えます。**
更新や再インストールのときは、チェックを入れないでください。

## データの保存場所

データはこのパソコンの中だけに保存されます(販売者のサーバーには送られません)。

- 保存場所: `%APPDATA%\com.mitsumoridesk.desktop\`
- 別のパソコンへ移るときは、「データ管理」でバックアップを作成し、一覧の「外部フォルダへ書き出す」で USB メモリなどへ保存します。新しいパソコンでは「データ管理」→「外部フォルダから取り込む」で読み込み、一覧から復元します。
