# PDF目視確認チェックリスト

このファイルは、**人間が実機で PDF を保存したあと**に見る項目です。
コードの component test は「文字が描画されること」までです。改ページ・フォント欠け・余白は自動では判定しません。

対象バージョン: `package.json` の値（現時点は 0.1.0。RC/正式版へ上げる判断は人間）
確認日:
確認者:
環境(OS / 機種 / 印刷ダイアログのPDF保存):

未実施の項目を「崩れなし」と書かないこと。

fixture の識別文字列は `tests/fixtures/pdf-visual/cases.ts` と一致させています。
アプリ上では同等の見積を手入力(または練習データ＋明細追加)し、発行 → 印刷 → PDF保存してください。

共通の見方:

- OS印刷倍率は 100%
- 用紙は A4
- 日本語が欠けていないか
- ヘッダー・合計欄がページ途中で不自然に分断されていないか
- 明細の途中で行が縦に裂けていないか(可能な範囲)
- 長い文字列が枠外へ出ていないか
