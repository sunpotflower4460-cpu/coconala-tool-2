# はじめにお読みください(初回設定ガイド)

「見積・請求書デスク」を使い始める前に、この案内に沿って初回設定を行ってください。所要時間はおよそ5〜10分です。

初回販売の対象OSは macOS です。Windows版は実機確認が完了するまで正式対応としません。

## この案内の対象

- はじめてこのアプリを起動した方
- 初回設定を途中でやめてしまい、続きから再開したい方

## 始める前に

- インターネット接続は不要です。作成したデータはすべてこのパソコンの中に保存されます。
- 入力した内容はあとからいつでも変更できます。完璧を目指さず、まずは1件ずつ登録してみてください。
- 何もわからないまま進めるのが不安な場合は、先に「練習モード」(データ管理画面)でサンプルデータを使って操作を試すこともできます。

## 手順

### ステップ0: 起動

アプリを開くと、ホーム画面に「初回設定をはじめる」ボタンが表示されます。押して初回設定ウィザードを開始してください。

### ステップ1: 会社情報

- 会社名・屋号(必須)
- 代表者名、住所、電話番号、メールアドレス(任意)
- 適格請求書発行事業者番号(インボイス登録をしている場合のみ)
- 振込先(銀行名・支店名・口座種別・口座番号・口座名義)
- 見積書の有効期限日数、支払期限日数の初期値

これらは請求書・見積書などに印字される情報です。あとから「会社情報」画面でいつでも修正できます。

### ステップ2: 税設定

消費税計算の端数処理方法を選びます。特別な事情がなければ「切り捨て」を選んでください(最も一般的です)。

### ステップ3: 顧客登録

よく取引する顧客を1件登録します。あとで「顧客」画面からまとめて追加したり、CSVで一括登録したりできます。今は登録せずに「スキップ」しても構いません。

### ステップ4: 価格表登録

よく使う商品・サービスとその単価を1件登録します。こちらも「スキップ」可能で、あとから価格表画面やCSV取り込みでまとめて登録できます。

### ステップ5: 練習見積

ステップ3・4で顧客と商品を登録した場合、その内容を使って練習用の見積書を1件作ってみることができます。実際の操作感を確認するのに役立ちます。この見積はあとで自由に編集・削除できます。

### ステップ6: 完了

「はじめる」を押すと初回設定は完了です。以降はホーム画面から通常の操作を開始できます。

## 途中で中断してしまった場合

初回設定は画面を閉じても自動的に保存されており、次に開いたときに続きから再開できます。左メニューの「ホーム」からいつでも中断・再開が可能です。

## 次にすること

- 最初の見積書を作ってみましょう(「見積書」→「新しい見積書を作る」)
- 顧客・価格表をまとめて登録する場合は「CSV取り込み」画面をご利用ください
- 操作でわからないことがあれば「ヘルプ」画面のFAQをご確認ください
