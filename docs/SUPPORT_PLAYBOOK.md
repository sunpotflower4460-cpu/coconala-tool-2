# サポート対応の手引き(販売者向け)

お問い合わせは、ココナラのトークルーム(取引完了後はダイレクトメッセージ)だけで受けます。
メール・LINE など外部の連絡先は、ココナラの規約により案内しません。

## まず確認すること

1. 使っている OS とアプリのバージョン(「バージョン情報」画面)
2. 何をしたら、何が起きたか(画面の表示文をそのまま)
3. 診断ファイル(「データ管理」→「診断ファイルを保存」)または、エラー表示の「診断情報をコピー」の内容
   - 診断ファイルには顧客名・会社名・APIキーなどは入っていません。件数とバージョン情報だけです
   - **顧客データそのもの(バックアップファイル等)は受け取らない**でください。個人情報を預かることになります

## よくある問い合わせと返答例

| 内容                                   | 返答の要点                                                                                                                                            |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Mac で「開発元を検証できない」と出る   | 署名済み版なら出ない。`-unsigned` 版を渡していないか確認。出た場合は「システム設定→プライバシーとセキュリティ→このまま開く」                          |
| Windows で「PCが保護されました」と出る | 「詳細情報」→「実行」。手順書の該当ページを案内                                                                                                       |
| 印刷に「未認証版」と入る               | バージョン情報でライセンスキーを登録。キー全体(`MDK1.` から最後まで)を貼る。古いバックアップを復元した場合は再登録                                    |
| ライセンスキーが「正しくありません」   | 途中で切れていないか確認。台帳の番号で作り直して再送(`docs/SELLER_OPERATIONS.md`)                                                                     |
| PDFの保存方法が分からない              | 印刷画面の「PDFとして保存するには」を開くよう案内                                                                                                     |
| 合計金額が合わない気がする             | 合計欄は「明細合計→値引き→小計→税率ごとの対象額・消費税→合計」。端数処理の設定(帳票の設定)を確認                                                      |
| パソコンを替えたい                     | データ管理でバックアップ→外部フォルダへ書き出す→新PCで取り込んで復元。キーもバックアップに含まれる                                                    |
| AIが使えない                           | AIは任意機能。APIキー・通信・料金は購入者の契約。本アプリのサポート対象外の部分を丁寧に説明                                                           |
| データが消えた                         | 慌てて操作しないよう伝える。データ管理のバックアップ一覧から復元できるか確認。Windowsでアンインストール時に「データを削除」にチェックしていないか確認 |

## 不具合だったとき

1. 診断情報と手順で再現を試み、GitHub の issue に記録します(購入者の個人情報は書かない)
2. 修正版を作り、`docs/SELLER_OPERATIONS.md` の「更新版を配るとき」の手順で配布します
3. 販売停止条件(重大な計算誤り・データ消失・復元不能・秘密情報漏えい・発行済み書類の変化)に当たる場合は、出品を一時停止してから対応します
