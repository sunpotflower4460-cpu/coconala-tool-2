# 見積・請求書デスク 利用マニュアル

<!-- support-contact: PENDING -->

このマニュアルは、正式販売時にPDFとして同梱する利用マニュアルの下書きです。画面の実際の文言と差異がないか、公開前に最終確認してください。

初回販売の対象OSは macOS です。Windows版は実機確認が完了するまで正式対応としません。CI上のWindowsビルド成功は正式対応を意味しません。

## 1. このアプリについてできること

「見積・請求書デスク」は、購入者自身のパソコンだけで完結する見積書・請求書・納品書・領収書の作成アプリです。

- インターネット接続なしで、すべての基本機能(会社情報・顧客・価格表の登録、見積書等の作成・印刷)を利用できます
- 作成したデータはこのパソコン内のみに保存され、外部へ送信されません
- 「AI文章読み取り機能」は任意機能で、使わなくてもすべての基本機能が利用できます

## 2. 初回設定

初回起動時は`docs/QUICK_START_GUIDE.md`(初回設定ガイド)に沿って設定してください。会社情報・税設定・顧客・価格表を登録し、必要に応じて練習見積を作成します。

## 3. 画面ごとの説明

### 3.1 ホーム

初回設定の状態、見積書の件数を確認できます。

### 3.2 顧客

取引先の情報(名前・担当者名・住所・連絡先・備考)を登録・編集・削除できます。書類から参照されている顧客は削除できません。

### 3.3 価格表

商品・サービスの名称・単位・単価・税区分・原価・最小数量を登録・編集できます。使わなくなった商品は削除ではなく「無効化」することで、過去の書類との整合性を保ったまま一覧から外せます。

### 3.4 見積書・請求書・納品書・領収書

いずれも同じ操作方法です。

1. 「新しい○○を作る」から作成を開始する
2. 顧客を選び、明細(品目・数量・単価・税区分・値引き)を追加する
3. 「下書きを保存」でいつでも保存できる
4. 内容が確定したら「発行する」を押す。発行すると書類番号が採番され、その時点の会社情報・顧客情報・金額が固定される(以後は変更できない)
5. 発行済みの書類は「印刷プレビューを開く」からOS標準の印刷ダイアログでPDF保存できる
6. 見積書は請求書・納品書へ、請求書は領収書へ変換できる(変換すると新しい下書きが作られ、元の書類の状態も自動的に進む場合がある)
7. 内容を直したい場合は「複製して下書きを作る」から新しい下書きを作成する(発行済みの書類そのものは変更できない)

書類の状態は次のように遷移します: 下書き→発行済み→(承認済み/却下/請求済み/入金済み/取消)。

### 3.5 CSV取り込み

顧客・価格表を表計算ソフトで作ったCSVファイルからまとめて登録できます。

1. 対象(顧客/価格表)を選ぶ
2. 「見本CSVをダウンロード」で列の形式を確認する
3. CSVファイルを選択する(文字コードは自動判定されるが、文字化けする場合は手動で切り替えられる)
4. 列のマッピングを確認・調整する
5. プレビューでエラー行がないか確認する(「エラー行だけ表示」で絞り込める)
6. 重複時の扱い(スキップ/上書き)を選ぶ
7. 「取り込む」を押すと、取り込み前に自動でバックアップが作成されたうえで登録される

### 3.6 問い合わせ読み取り(AI機能・任意)

AI設定画面でAI機能を有効にし、APIキーを登録している場合のみ使えます。問い合わせ文を貼り付けると、価格表に実在する商品と照合した明細候補が表示されます。金額は必ず価格表の値が使われ、AIが金額を生成することはありません。候補を確認・編集し、選んだ明細から見積下書きを作成できます。

### 3.7 会社情報

自社の名称・住所・連絡先・振込先・インボイス番号等を設定します。

### 3.8 AI設定

AI文章読み取り機能の有効/無効、モデルID、APIキーの登録・削除・接続確認を行います。APIキーはOSの資格情報ストアにのみ保存されます。

### 3.9 データ管理

- **練習モード**: サンプルデータを自動作成して操作を試せます。「練習データを一括削除」で練習データのみを安全に消せます
- **バックアップ**: 作成・一覧・復元ができます。復元前には現在のデータを自動退避し、失敗時は元に戻せます
- **診断ファイル**: 個人情報・秘密情報を含まない集計情報のみのファイルを保存し、サポートへの問い合わせに使えます

### 3.10 ヘルプ

画面の説明・FAQ・インストール案内・サポート範囲を確認できます。

### 3.11 バージョン情報

アプリのバージョン、データベースの状態、ライセンス状態、更新確認の設定を確認できます。

## 4. よくあるご質問

FAQはアプリ内の「ヘルプ」画面もあわせてご確認ください。
